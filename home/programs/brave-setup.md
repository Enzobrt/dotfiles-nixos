# Brave - Configuración

## 1. Instalación

- [ ] Instalar Brave mediante Home Manager
- [ ] Iniciar sesión si es necesario

## 2. Apariencia

### Font

- Content → Customize fonts (brave://settings/fonts)
- Poner JetBrains Mono en todas las opciones

### Colores

- Morado / azul

## 3. Atajos

- [ ] Search engine → Site search (brave://settings/searchEngines)

### NixOS Packages

  - Nombre: `NixOS Packages`
  - Shortcut: `:np`
  - URL: `https://search.nixos.org/packages?query=%s`

### NixOS Options

- [ ] Nombre: `NixOS Options`
- [ ] Shortcut: `:no`
- [ ] URL: `https://search.nixos.org/options?query=%s`

## 4. Marcadores

- [ ] Importar marcadores (brave://settings/importData)

## 5. Extensiones

- [ ] KeePassXC Browser (https://chromewebstore.google.com/detail/keepassxc-browser/oboonakemofpalcgghocfoadofidjkkk)
- [ ] FastForward (https://chromewebstore.google.com/detail/fastforward/icallnadddjmdinamnolclfjanhfoafe)

## 6. Brave settings

### Startup

- [ ] `Continue where you left off` (brave://settings/getStarted)

### Descargas

- [ ] Download location: `~/Downloads` (brave://settings/downloads)
- [ ] Ask where to save each file
